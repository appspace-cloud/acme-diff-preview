Closes 2 critical gaps found in an internal security/reliability review.

- **C1 (security):** a negative `Content-Length` bypassed the webhook body-size cap on both `/diff-preview/webhook` and `/jfrog-webhook`, letting an unauthenticated request read an unbounded body. Fixed by rejecting non-positive lengths.
- **C2 (reliability):** the liveness heartbeat refreshed `/healthz` every 30s unconditionally, so a wedged main loop would report healthy forever and never get restarted. It now requires real progress or a known-safe idle state before refreshing.
